# Velvet Scent - Premium Fragrance eCommerce Store

A modern, fully responsive eCommerce website showcasing premium fragrances with an integrated WhatsApp checkout flow for seamless customer conversions.

## ✨ Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Product Showcase**: Beautiful display of fragrance collections with detailed product information
- **WhatsApp Integration**: Direct checkout via WhatsApp for enhanced customer engagement
- **Smooth Interactions**: Modern UI/UX with smooth animations and transitions
- **Premium Aesthetic**: Carefully crafted visual design reflecting luxury fragrance positioning
- **Fast Loading**: Optimized performance for quick load times
- **SEO Friendly**: Structured for search engine visibility

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Design**: Custom CSS with mobile-first responsive approach
- **Messaging**: WhatsApp Business API Integration

## 🚀 Getting Started

### Installation

1. Clone or download the repository
2. Open `index.html` in your web browser
3. No build process or dependencies required

### Usage

- Browse fragrance collections on the main page
- Click on products to view detailed information
- Use the WhatsApp checkout button to complete purchases directly

## 💬 WhatsApp Checkout

Customers can seamlessly transition to WhatsApp to:
- Ask questions about fragrances
- Complete purchases with personalized service
- Receive order confirmations and shipping updates
